# Contributing

This repository is the official SAUD TECHNOLOGY site
([saudtechnology.com](https://saudtechnology.com)). It is a single Next.js
application with repository-level quality, security, and release gates.

Contributions must keep that boundary: product code under `src/` and `public/`,
governance at the root.

## Toolchain

Declared in `package.json`:

```text
Node.js  >= 24.14.0
pnpm     12.4.1   (packageManager field + Corepack)
```

```bash
corepack enable
corepack prepare pnpm@12.4.1 --activate
pnpm infra:script:setup
```

Do not edit `pnpm-lock.yaml` by hand.

Hooks are installed by `scripts/prepare-lefthook.mjs` when the directory is a
Git work tree. Do not skip hooks to land a change.

## Branch and commit

Branch:

```text
<type>/<short-description-in-kebab-case>
```

Types: `feat`, `fix`, `docs`, `style`, `refactor`, `perf`, `test`, `chore`,
`ci`, `revert`, `release`.

Commit (Conventional Commits, subject in lower-case):

```text
feat: add hero section
fix: correct sitemap lastModified timezone
```

## Pull requests

Every product or tooling PR includes a changeset:

```bash
pnpm infra:release:changeset
```

The Version Packages PR generated by Changesets is exempt.

PR description must state:

- what changed and why;
- how it was verified (`pnpm lint:check:all`, `pnpm build`, and relevant tests);
- security impact (secrets, headers, dependencies).

## Local verification

```bash
pnpm lint:check:all
pnpm test:sast:all
pnpm test:unit
pnpm build
```

## Release

1. Merge to `main` with changesets.
2. Changesets opens or applies the Version Packages PR.
3. That merge runs **Create Unified Tag and GitHub Release** and publishes
   `v$version` on GitHub. Packages are private; nothing is published to npm.

## Scope

Keep application changes and governance changes in separate PRs unless one
cannot land without the other.
