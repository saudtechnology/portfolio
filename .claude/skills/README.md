# Skills

On-demand procedures. Facts stay in `/AGENTS.md`.

| Directory            | Load when                                             |
| -------------------- | ----------------------------------------------------- |
| `next-static-export` | Routes, metadata, CSS, SEO, `out/`, Pages             |
| `changeset-release`  | Changeset file, Version Packages, tag, GitHub Release |

Do not add a skill for a command that already exists in `package.json` unless the _procedure_ is longer than the command.
